# Dashboard v0.1

`saude.json` é gerado por `npm run dashboard` e provisionado automaticamente, com fonte Prometheus de UID estável. O dashboard é somente leitura pela interface; alterações são feitas na origem versionada.

Inclui síntese gerencial, qualidade da observação, disponibilidade, estados de alertas, desempenho, eventos de autenticação e infraestrutura. O link do procedimento aponta para a API local na porta 3000, também encaminhada ao usar túnel SSH.

As cinco visões completas do produto final não são antecipadas nesta sprint. Não há percentuais fictícios de conformidade, riscos ou incidentes para preencher espaços sem fonte real.
